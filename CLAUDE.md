# Istruzioni per Claude in questo repository

- **Analytics, Ads, Search Console, SEO**: per qualunque lavoro su tracciamento, eventi, conversioni, campagne Google Ads, Search Console, keyword, redirect o report, usa la skill `google-marketing-specialist` (`.claude/skills/`). Per i lavori più ampi delega all'agente `google-marketing-specialist` (`.claude/agents/`). Ogni nuovo pulsante, link o form deve essere tracciato secondo `src/influencee/v2/ANALYTICS-PIANO.md`.
- **Comandi bash**: concatenati e con output troncato, modifiche multiple con un unico script, mai credenziali in chiaro (vedi la sezione bash della skill).
- **Sito influencee v2** (`src/influencee/v2/`): solo funzioni reali dell'app, niente AI, solo creator italiani, nessuna riga solo testo, hero su nero con evidenziazione verde acido. Build: `npx vite build --config vite.site-v2.config.ts`.
- **Plugin WordPress** (`wp-plugin/`): cinque plugin separati, tutti basati su **influencee-core** (motore pagine, SEO/GEO/AEO, tracciamento GA4 `inft-track.js`, CSS base `inft-base.css`, redirect, MCP). `influencee-tools` = solo i tool (niente offerte di lavoro); `influencee-pagine` = pagine nuove/sostituzioni, profili creator, elenco; `influencee-articoli` = articoli in HTML5 senza Elementor; `influencee-annunci` = offerte di lavoro collegate ad app.influencee.it (campi uguali all'app, account alla fine). Stesso URL delle pagine WordPress, CSS isolato, eventi GA4 sul tag del sito, lead verso tandem-forms con `<form data-tandem>`. Ogni nuovo tipo di pagina va in un plugin a sé che usa il Core. A parte c'è `influencee-pulizia` (controllo e pulizia di WordPress, indipendente dal Core, si accende solo quando serve). Build: `node scripts/build-wp-plugin.mjs` → `dist-wp/<plugin>.zip`. Prima di consegnare: test su un WordPress locale. Guida: `wp-plugin/influencee-core/LEGGIMI-INSTALLAZIONE.md`.
